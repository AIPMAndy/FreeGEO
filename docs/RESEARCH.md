## 1. 第一性原理：GEO 是一个漏斗而非排名开关

用户提出真实需求 → 引擎是否联网 → 候选内容可发现、可访问 → 相关证据进入生成上下文 → 答案使用事实、显示引用或推荐 → 用户点击或通过其他途径联系 → 任务完成或付费。各节点存在条件概率；后节点不能由前节点单独推出。曝光指标也不能代替收入。在只需一个简单事实时，AI 可能直接回答；复杂任务仍需要可用工具、体验、报价、独特数据或人与人交付。

设计原则：对齐真实任务；不编造证据；可追溯记录；在同平台、终端、地区、语言、问题集合下多次采样；优先改进瓶颈；按边际产出安排预算。FreeGEO 的衡量目标是每单位投入产生的可归因有效线索或任务完成，不是虚构全网排名。

## 3. 独立研究验证

- Aggarwal 等（KDD 2024）[GEO 论文](https://arxiv.org/abs/2311.09735)：给出了可见性实验框架，策略收益因任务领域而异。论文特定基准上报告最高约 40% 的可见性改善，并非生产平台保证。启发：记录方法和对照，而非写死权重。
- [GEO Citation Lab](https://github.com/yaojingang/geo-citation-lab)：公开库区分信源选择、内容吸收与实体呈现；其静态观察不能直接推导趋势或严格因果。README 所述中文引用记录与跨平台 prompt 样本各有独立口径。启发：不同终端分别观测，问答格式不设万能加分。
- [Google AI features](https://developers.google.com/search/docs/appearance/ai-features)：常规 SEO、可访问文本、结构化数据与可见内容一致仍重要；没有专门 AI schema 或文本文件的入场要求。启发：检查技术基础；llms.txt 仅实验可选，不当作排名开关。
- [OpenAI Crawlers](https://developers.openai.com/api/docs/bots)：OAI-SearchBot 负责搜索发现，GPTBot 涉及训练用途，ChatGPT-User 对应用户发起访问。各用途独立配置，不能用某类 UA 访问推断已被引用，UA 也可以伪造。
- [GEORank](https://github.com/yaojingang/GEORank)、[GEOFlow](https://github.com/yaojingang/GEOFlow)、[GEOInflow](https://github.com/yaojingang/GEOInflow)、[GEOHub](https://github.com/yaojingang/GEOHub)、[yao-geo-skills](https://github.com/yaojingang/yao-geo-skills)：分别覆盖诊断、内容运营、日志分析、Agent 工作流及实操技能。GEOFlow/GEOHub 的 AGPL 与其他项目许可不同，不能无视授权复制代码。FreeGEO 采用独立实现，引用原项目作为进一步研究入口。

## 4. 竞争格局与最小产品

已有 [Andy GEO Handbook](https://github.com/AIPMAndy/geo-handbook) 提供课程、实验和工具，FreeGEO 不再重复建设一整套教材。产品差异是将问题、事实、答案观测、干预和商业事件连接在一个可持久化、可导出的本地工作台中。首版为单个活跃工作区，可通过 JSON 备份切换项目。无账户，无模型 API，无自动发布，不绕过平台防护。浏览器存储不是云同步；用户需主动导出备份。

| 优先级 | 模块 | 实际验收 |
|---|---|---|
| P0 | 项目和问题库 | 问题 ID、场景、意图、目标页、需求依据；每个问题可被观测引用 |
| P0 | 品牌事实库 | 主张、证据 URL、证据类型、验证状态；过期提醒 |
| P0 | AI 回答记录 | 平台、终端、地区、语言、日期、批次、状态、联网、提及/推荐/引用及原始证据 |
| P0 | 实验台 | 单一干预、基线与复测批次、匹配问题条件、差值与覆盖，不作因果承诺 |
| P0 | 商业事件 | 类型、发生日期、金额及币种、归因类型、来源证据；金额按币种分别汇总 |
| P0 | HTML 本地体检 | 检查页面 title、描述、主标题、canonical、noindex、JSON-LD、可见文本；不自动联网、不宣称真实评分 |
| P0 | 数据导入导出 | 验证版本、记录 ID、外键和 URL；异常拒绝；样例标为 DEMO |
| P1 | 权限与真实站点采集 | 经授权导入服务器日志、GSC/Bing 报表、真实浏览器样本；区分 UA 识别可信度 |
| P1 | 多项目并行、批量 CLI、内容证据 | 批量导入、自有模板、可复现查询、来源覆盖、版本管理 |
| P2 | 经授权模型/搜索适配器 | 独立标注 API/Web 样本，不绕过限制、不伪造实测 |

## 5. 指标与实验协议

- 分母：每个指标中成功且明确标为是/否的回答数；失败或未知单列。提及率=含目标品牌回答/提及状态已知的成功回答；推荐率和自有 URL 引用率同理，各为独立观测项。联网率=已知联网状态中的联网回答数/已知联网状态回答；未知不混入。
- 自有引用依据是回答中的真实链接，不能仅凭出现名称判定。正向/负向与推荐分别记录；不自动以文本匹配推断事实。
- 分层维度：问题、平台、界面、地区、语言，观察日期及批次。先固定样本计划；记录失败，不能只保存正例。每一批次保存时间及证据。可采用重复采样，必要时用区间估计；样本存在相关性时不可误解置信区间。
- 实验比较：同一问题、平台、界面、地区、语言组合的基线和复测，按组合等权平均；报告各批次数量、覆盖和差值。季节性、竞争和引擎更新均可能混杂；保留未修改对照页，不能把前后差异直接说成因果。
- 商业结果：分别统计已记录的直接、辅助、未知事件；不把同一事件多触点重复归因。币种分开，收入不是利润。无数据为缺失，不填 0。

## 6. 星觉科技自用验证计划

先选已有真实工具（如 FreeWatermark、FreePublish）以及 AI 产品求职咨询等已上线业务，用自己的真实用户问题作基线。每类先采 10 个经过用户原话验证的问题 × 两个平台 × 每平台 3 次；60 次观察仅为试点，不代表平台全量。固定地区、语言、终端并保留所有失败。只改一项（例如：工具页任务入口、产品参数或真实案例证据）。7–14 天后同口径复测，记录点击、咨询与付费证据。有效则扩大，不有效则复盘，不因沉没成本继续铺低价值内容。样例仅为计划，不是已完成测量。

商业模式：FreeGEO 免费；官网链接承接真实诊断、咨询与企业实施；按可控的工作和交付计价，不以固定 AI 排名承诺销售。现阶段优先验证工具是否能被真实客户重复使用，然后才开发复杂的自动采集后台。
