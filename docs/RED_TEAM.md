# FreeGEO v0.2 对抗式审核 / Release candidate

**2026-11-24 · 审核范围：v0.1 源码、v0.2 改动和可执行测试。**

目标不是堆功能，而是让新手在没有 GEO 专业背景的情况下完成「业务目标 → 真实问题 → 基线 → 修复 → 同条件复测 → 业务结果」闭环。

| 攻击 | 真实问题 | 处理 | 验证 |
|---|---|---|---|
| 无经验新手 | 空白项目仅提示录入 | 业务向导与规则驱动行动清单 | DOM 隔离测试通过 |
| 表单渲染 | 给 textarea 只读 type 赋值，真实浏览器抛错 | 仅为 input 设置 type | DOM 隔离测试录入通过 |
| 域名伪造 | 任何 URL 可被标为自有 | 精确主机/路径，拒绝歧义编码；未核验为未知 | Node 测试通过 |
| 时间倒置 | 干预后样本可混入基线 | 严格排除同日和不正确时间 | Node 测试通过 |
| 误读小样本 | 单次结果易被误作平台总体 | 分母、未知、覆盖、描述区间、匹配提示 | Node 测试通过 |
| 重复 URL | 可能重复统计同一回答来源 | 单回答去重 | Node 测试通过 |
| 批量录入 | 人工逐条录入；表格公式注入 | 采样 CSV + 全量验证原子追加 + 转义 | Node 测试通过 |
| 错误导入 | 空 ID/坏外键/非法状态/重复行 | 严格校验 | Node 测试通过 |
| 损坏旧存储 | 写入可能覆盖不可解析旧数据 | 原始恢复下载与明确确认 | 逻辑已实现，真实浏览器持久化待验 |
| 错误 HTTP 与机器人规则 | 静态源代码无法证明公网可抓取 | 新增 Site Doctor 及明确待核验 | Python 离线单测通过，真实请求待验 |
| 安全请求 | 恶意 URL 可能指向内网 | 显式公网请求、DNS/IP 检查及连接固定、重定向/大小限制 | Python 安全边界测试通过；真实网络待验 |
| 恶意 HTML | 可能执行脚本或请求外部资源 | 继续使用 inert template 与 textContent | 隔离 DOM 测试无外部请求/脚本执行 |

## 下一阶段工程优先级

P0：首先上线并通过真实浏览器 CI，真实用户测试；持久化多项目/操作版本，改善大数据表格性能。对自己的两个官网和开源项目完成真实基线，严格区分手工观测与官方聚合指标。

P1：授权 API 适配器与成本上限、Search Console / Bing AI Performance 导入、引用页差距核对、竞品自愿设置、可执行内容修复工作流与行业模板。统一记录采集时间、模型版本、地域、联网状态和会话设置。对固定样本面板增加观察者一致性、随机化和控制组设计。

P2：Agent Skill、MCP、持续任务和团队协作；执行和对外发布前的人类审核。绝不使用自动批量刷答案、假榜单、虚假评价和绕过规则的采集方式。

## 尚未关闭的风险

- 原始 X 线程仍未逐帖获取；不能把 29 个公开会议单元称作该线程完整研究。
- 当前是本地单工作区，未实现真实 API 自动采样、团队权限、服务器端备份和完整跨浏览器测试。
- URL 边界是用户声明，不是域名所有权证明。引用列表仍由实际观察者填写，程序无法自行核验模型网页中的引用。
- Wilson 区间仅为独立二项假设下的描述性参考，模型重复回答可能相关；实验没有随机控制，无法证明单一干预因果。
- 技术检查不会证明索引或推荐，robots 解析只覆盖常见规则和公开访问；不应为提高曝光而关闭私密页保护。
- 尚未在真实独立用户群验证用户成功率、商业效果或全球竞品优势。只有后续实际数据可以支撑上述结论。
