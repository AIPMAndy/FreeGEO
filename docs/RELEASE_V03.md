# FreeGEO v0.3 · 对抗式验收与发布门禁

## 版本结论

候选发布版：源代码、说明、MIT 协议、CLI、HTML 应用、对抗测试及两个真实业务试点已形成。不是全球第一的实证证明。正式公网发布与真实用户验收仍需完成。

| 攻击角色 | 失败方式 | 本版修复 | 证据 |
|---|---|---|---|
| 零基础用户 | 填完不知道做什么 | 行动卡、问题缺口、修复台账、内容 Brief、真实试点 | 隔离 DOM 测试与可导入试点 |
| 数据红队 | 换提示词、地区或增加采样槽 | 固定面板验证原文、ID、序号、条件、批次；拒绝额外槽 | tests/workflow.test.js |
| 客户质疑者 | 没有执行证据就宣称完成 | 复核条件、执行与复核凭证、验收者与日期 | tests/workflow.test.js、browser_dom.py |
| SEO 工程师 | 静态源码检查冒充真实索引 | 区分本地 HTML、真实 HTTP/robots、站长数据未知；诊断可转为任务 | tests/test_site_doctor.py、browser_dom.py |
| 竞争对手 | 竞品链接被误当推荐率 | 只报告实际记录中 URL 范围命中次数及成功回答分母 | tests/workflow.test.js |
| 安全工程师 | 切换项目覆盖记录或损坏备份 | 多项目隔离、旧版迁移、完整导出、存储异常保护、其他窗口改动提示 | tests/workflow.test.js、browser_dom.py |
| 费用攻击者 | 自动采集擅自产生费用 | 官方 API 默认 dry-run，显式双参数执行，最多 50 次且默认 3 次，输出 token 限制；遇错停，不自动重试 | tests/test_api_sampler.py |
| 隐私攻击者 | 爬虫报告泄露 IP 或访问路径 | 离线汇总 User-Agent 声明和状态，不导出 IP/URL/原始 UA；不把 UA 冒充真实爬虫 | tests/test_crawler_logs.py |

## 本次实测结果

- JavaScript 核心及对抗测试：46/46 通过。
- Python 技术诊断/API 解析/日志分析测试：17/17 通过。
- Chromium 隔离 DOM 操作测试：通过，包含旧版核心流程、竞品、固定面板、证据验收、修复任务、多项目、移动端。使用模拟浏览器存储；并非真实 HTTP 部署验收。
- CLI：两个试点数据格式校验、执行报告、Agent 任务包、离线网站诊断均已实际运行。
- 本地 HTTP 冒烟测试：环境拒绝 Chromium 访问 `127.0.0.1`（ERR_BLOCKED_BY_ADMINISTRATOR），不能宣布通过。
- 官方 API 真实调用：未执行；模拟响应与 dry-run 测试通过，未使用密钥或产生 API 费用。
- 真实网站：两份试点基于 2026-11-24 公开可见页面整理，事实范围限于公开自述。AI 实测、实际索引及转化数据仍未知。
- 仓库部署：独立 FreeGEO 仓库尚未建立，未推送或发布。

## 正式发布的不可绕过门禁

1. 公共仓库启用 CI：核心、Python、真实 HTTP 浏览器冒烟都通过，部署后手工测试下载、重载、导入和移动端。
2. 真实用户测试：招募至少 10 个此前未接触 GEO 的用户（目标，不是已完成样本）。给一个真实业务 URL，不解释术语，记录首次得到可执行任务耗时、卡点、任务完成及证据质量。目标中位时间 ≤5 分钟，独立任务完成率 ≥80%；以实际日志公开样本数、失败和局限。
3. 真实业务实验：至少一个页面有完整基线、明确干预、同条件复测；如无改善也如实报告。不把单次回答或流量波动冒充增长因果。
4. 数据口径：失败与未知单列、平台和终端分开、计数分母明确、竞品 URL 命中不等于推荐、真实/演示数据严格区分。
5. 安全与成本：不自动花钱、不外发资料、不自动改站，用户拥有可导出的完整工作区；记录 API 成本和模型版本。实际 API 接入需在授权账户验证，再扩展其他官方入口。

## 下轮高价值缺口

- 用真实站长后台和实际 AI 结果建立证据，不应先加更多仪表盘。
- 正式引入可授权的 Search Console / Bing 数据导入及趋势监测；不通过模拟浏览器绕过平台限制。
- 进一步验证 API 地区语义、真实费用与模型版本变化；增加其他平台的官方接口适配。
- 提供可回滚的协作交付、证据文件哈希及审计日志；本地用户记录可以修改，验收并非第三方签名或不可篡改证明。
- UI 多语言与无障碍用户测试、实际性能压测。不要将测试数量本身当作产品质量或市场领先证明。

来源研究的原始 X 帖仍未完整取得；29 个大会补充单元研究不是逐帖验收。
